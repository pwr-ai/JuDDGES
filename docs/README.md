## 🔧 Quick Start Guides

### For Developers

```bash
# 1. Setup environment
./setup.sh  # or setup.bat on Windows

# 2. Run data acquisition
python scripts/data_acquisition/pl_court_data_pipeline.py

# 3. Generate embeddings
dvc repro embed

# 4. Ingest to Weaviate
python scripts/embed/ingest_to_weaviate.py

# 5. Run fine-tuning
dvc repro sft

# 6. Generate predictions
dvc repro predict_raw_vllm

# 7. Evaluate
dvc repro evaluate_ngram_based
```

See [Getting Started Tutorial](tutorials/GETTING_STARTED.md) for detailed setup instructions.

### For Researchers

**Using JuDDGES Data**:
```python
from datasets import load_dataset

# Load Polish court dataset
ds = load_dataset("JuDDGES/pl-court-raw-sample")

# Load Swiss franc loans dataset
loans = load_dataset("JuDDGES/swiss_franc_loans_instruct")
```

**Semantic Search**:
```python
from juddges.data.judgments_weaviate_db import JudgmentsWeaviateDB

# Connect to Weaviate
db = JudgmentsWeaviateDB(url="http://localhost:8080")

# Semantic search
results = db.search_semantic(
    query="Swiss franc loan conversion",
    limit=10
)
```

See technical guides for detailed examples.

**Gemini Information Extraction** ⭐ **NEW**:
```bash
# Test single extraction
./scripts/extraction/run_extraction.sh test_langfuse_simple.py

# Run 10 examples with Langfuse logging
./scripts/extraction/run_extraction.sh run_10_examples.py

# View results
# Visit: https://legal-ai-langfuse.augustyniak.ai
```

See [Gemini Extraction Tutorial](tutorials/GEMINI_EXTRACTION.md) for detailed usage.
